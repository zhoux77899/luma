# User guide site

Visitor mode: Persuade on `/zh` and `/en`; Read on `/:version/:locale/**`.

Audience: Cardputer ADV owners flashing or using LUMA. Job: open the User guide that matches their build, or the current main draft. Action: choose language, version, and a topic. Proof: firmware screenshots from `docs/user-manual/assets/`. Constraints: DESIGN.md tokens and Logo; no per-release copies in git; stub when a Release has no handbook.

## Direction contract

THESIS: A four-petal LUMA cover that hands the reader a versioned handbook, not a generic docs index.

OWN-WORLD: Nippon neutrals (Gofun/Kuro canvases, Sumi text) with Fuji/Momo/Tamago/Byakuroku petals; beUI chrome restyled onto those tokens.

STORY: This is LUMA for Cardputer ADV. Read the current User guide or a frozen Release, including an honest stub.

FIRST VIEWPORT: Full-viewport cover under a borderless header. Logo and the LUMA word on one line, one-line offer, SETTINGS/NOTES/DOTS as a trait list, primary CTA into `/latest/{locale}/getting-started`, secondary to the GitHub repo; real firmware screenshots as proof, not a card grid.

FORM: Established firmware world; Vite + React + public @beui; seed skipped per plan.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
