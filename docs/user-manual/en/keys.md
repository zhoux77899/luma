# Keys

LUMA reads one key at a time. The Footer prints short labels for the keys that matter on the current screen. Those labels are `Ent`, `Esc`, and `Del`.

| Hardware | What LUMA does | Footer label |
| --- | --- | --- |
| Enter, or the button beside the screen (BtnA) | Confirm | `Ent` |
| Esc | Back | `Esc` |
| Del or Backspace | Delete | `Del` |
| Arrow keys | Move | (no Footer label) |

Printable keys type text in Notes, the Wi-Fi password field, and DOTS names. A few letters are also commands inside DOTS. Each App page lists the Footer hints for that screen.

Esc in an App returns to the previous pane or dialog. If the App does not stay on that screen, Esc opens Launcher.

The keys page does not cover the Header. That lives on [Launcher](launcher.md).
