# Display

Display is a Settings category. Open [Settings](../settings.md), select Display, then Confirm into the Detail pane.

![Display](../../assets/luma-settings-display.png)

## Brightness

Brightness is 0 to 100. Left and Right change it by 10. The `-` / `_` and `=` / `+` keys do the same. The bar updates immediately.

## Theme

Theme preference is Dark or Light. Dark is the default. Left, Right, or Confirm flips it. The whole screen remaps at once.

There is no Light screenshot in this guide. The layout is the same: a light canvas and darker cards.
