# REMOTE

REMOTE shows one Remote and fires its Keys through Infrared. Cardputer ADV can transmit and cannot receive, so there is no learn screen. Open REMOTE from [Launcher](launcher.md).

The face keeps the Header and has no Footer. One Remote is on screen: a brand mark when one exists, and six Keys.

## Keys

Press the key. REMOTE does not wait for you to select a row and press Ent.

| Key | Cardputer |
| --- | --- |
| Power | `P` |
| Mute | `M` |
| Vol+ | `;` (Up) |
| Vol- | `.` (Down) |
| Ch- | `,` (Left) |
| Ch+ | `/` (Right) |

`[` shows the previous Remote. `]` shows the next one. Holding a key does not repeat.

The seven Brand remotes come first and cannot be edited or deleted: LG, TCL, Hisense, Samsung, Sony, Panasonic, and Philips. A key with no command does not transmit.

## Your Remotes

`N` starts an empty Remote or a copy of a Brand remote. REMOTE keeps at most sixteen Remotes, so there is room for nine of yours. When that room is gone, `N` shows `FULL`.

`E` edits a Remote you created: name, protocol, shared address, and the six commands. A custom protocol stores its pulse rules on that Remote only. Choose Distance, Width, or Manchester, then type the timings. `Del` on the face asks before deleting the whole Remote. Esc on the face returns to Launcher.

SDL preview logs `[IR]` and does not transmit.
