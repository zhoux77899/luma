# 按键

LUMA 一次读一个键。Footer（底栏）只打印当前画面用到的键，标签是 `Ent`、`Esc` 和 `Del`。

| 硬件 | LUMA 的动作 | Footer 标签 |
| --- | --- | --- |
| Enter，或屏幕旁的按键（BtnA） | Confirm（确认） | `Ent` |
| Esc | Back（返回） | `Esc` |
| Del 或 Backspace | Delete（删除） | `Del` |
| 方向键 | 移动 | （Footer 不标） |

可打印键在 Notes、Wi-Fi 密码框和 DOTS 名称里输入文字。DOTS 里还有几个字母命令。每个 App 页只列该画面的 Footer hint（底栏提示）。

在 App 里按 Esc 会回到上一层分栏或对话框。如果当前画面不留下你，Esc 打开 Launcher。

按键页不讲 Header（顶栏）。Header 在 [Launcher](launcher.md)。
