# System

System 是一个 Settings category。它只有一行 About。

打开 [Settings](../settings.md)，选 System，再在 About 上 Confirm。

![System](../../assets/luma-settings-system.png)

## About

![About](../../assets/luma-settings-system-about.png)

About 标明当前安装的构建：

- Version 是 Build identity（构建标识）。发行版是 `X.Y.Z`。未发布构建是 `X.Y.Z.{commit}`。
- Model 是 `Cardputer ADV`。
- 仓库卡片上是 `zhoux77899/luma`。

上下键在这三行之间移动。About 不能改任何东西。

Footer：`Esc back`。
