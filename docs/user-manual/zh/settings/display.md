# Display

Display 是一个 Settings category。打开 [Settings](../settings.md)，选 Display，再 Confirm 进入 Detail pane。

![Display](../../assets/luma-settings-display.png)

## Brightness

Brightness 从 0 到 100。左右键每次改 10。`-` / `_` 和 `=` / `+` 一样。条子会马上更新。

## Theme

Theme preference（外观偏好）是 Dark 或 Light。默认是 Dark。左、右或 Confirm 会切换。整个画面立刻换一套颜色。

本指南没有 Light 的截图。布局相同：浅色底，卡片更深一点。
