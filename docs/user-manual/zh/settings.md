# SETTINGS

Settings 是改设备偏好的 App。从 [Launcher](launcher.md) 打开。

画面左边是 Category pane（类别栏），右边是 Detail pane（详情栏）。上下键在当前栏里移动。Confirm 进入 Detail pane，或进入嵌套编辑。Esc 回到上一栏。在 Category pane 再按 Esc 回到 Launcher。

这个分栏的 Footer 是 `Ent ok` 和 `Esc back`。

六个 Settings category（设置类别）：

- [Display](settings/display.md)：Brightness（亮度）和 Theme（外观）
- [Sound](settings/sound.md)：Volume（音量）
- [Network](settings/network.md)：Wi-Fi 的 Status、Saved 和 Scan
- [Time](settings/time.md)：Time zone（时区）
- [Battery](settings/battery.md)：电量和一小时历史
- [System](settings/system.md)：About

Brightness、Volume 和 Theme 会立刻生效。离开 Settings 时 LUMA 才写入。
