# Four Content chrome modes replace the RFC single band

RFC #1 fixed Header 18 / Content 101 / Footer 16. v0.1 uses Header 32 and Footer 15 so Content can be 88 (both), 103 (Header only), 120 (Footer only), or 135 (full). Boot is full, Launcher is Header only with a 4-row card grid, and placeholder Apps keep Header plus Footer. Dialog stays a full-canvas overlay.
