# Theme uses DESIGN.md tokens in an explicit dark mode

Issue #6 requires a dark flat UI, while DESIGN.md forbids ad hoc HEX values and treats dark canvases as an explicit dark mode or Logo presentation. Dark Theme preference maps DESIGN.md tokens: `neutral-kuro` for Boot and App canvases, `neutral-sumi` for cards, `neutral-gofun` for primary text, `neutral-ginnezumi` for secondary text, and `spectrum-benimidori` for the default selection color. App canvas moved from `neutral-sumi` to `neutral-kuro` so `neutral-sumi` can be the Dark card fill without a stroke. Light invert, Boot following Theme preference, and the Light card token are in ADR-0008. Per-App Accent replaces that default after enter; see ADR-0009.
