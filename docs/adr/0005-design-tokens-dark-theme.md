# Theme uses DESIGN.md tokens in an explicit dark mode

Issue #6 requires a dark flat UI, while DESIGN.md forbids ad hoc HEX values and treats dark canvases as an explicit dark mode or Logo presentation. Dark Theme preference maps DESIGN.md tokens: `neutral-kuro` for the Boot screen, `neutral-sumi` for App canvases, `neutral-gofun` / `neutral-ginnezumi` for text, and `spectrum-benimidori` for selection. Light invert and Boot following Theme preference are in ADR-0008.
