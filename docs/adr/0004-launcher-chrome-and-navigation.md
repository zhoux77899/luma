# Launcher chrome is Logo plus civil time, not a self-card

Launcher is the Home role, not a card in its own grid. It uses Header-only chrome: a 28 x 28 Logo, the product word LUMA, and 24-hour civil time, with no page indicator, Footer, or KeyHint. LUMA is product chrome, not `Launcher::name()`. Header titles use the shared 10px font at size 2; civil time stays size 1. v0.1 registers Settings, About, and Notes without letter shortcuts; directional selection and Confirm open those Apps, and Back returns to Launcher.
