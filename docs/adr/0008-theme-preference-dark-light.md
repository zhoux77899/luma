# Theme preference selects Dark or Light token invert

RFC #1 named theme=1 high contrast, but v0.1 uses the existing DESIGN.md tokens as a polarity invert instead of a second palette. Theme preference 0 is Dark (Boot and App `neutral-kuro`, cards `neutral-sumi`, primary text `neutral-gofun`, secondary `neutral-ginnezumi`); 1 is Light (Boot and App `neutral-gofun`, cards `neutral-shironezumi`, primary text `neutral-sumi`, secondary `neutral-ginnezumi`). `neutral-shironeri` is not used. Boot follows the preference because Settings load before the Boot screen. This revises ADR-0005's earlier "App canvas is sumi / v0.1 is dark only / Boot is always kuro".
